Fishy server run guide

1. Activate virtual environment

PowerShell:
D:\Fishy\.venv\Scripts\Activate.ps1

2. Start the production RAG flow

This is the main RAG server now:
cd D:\Fishy\server\RAG
uvicorn trusted_rag_app:app --host 0.0.0.0 --port 8000 --reload

Notes:
- This uses the custom RAG core, not langchain2.py
- Flow: legal DB -> trusted cache -> Firecrawl fallback -> cache -> retrieve again -> answer
- Firecrawl is not a local server to start separately
- Firecrawl is only called by trusted_rag_app when fallback is needed
- If cloudflared is available, the app updates app_config.rag_url automatically

3. Start legal document ingest server

cd D:\Fishy\server\RAG
uvicorn legal_ingest_app:app --host 0.0.0.0 --port 8010 --reload

Use this server to ingest files into noidung2 via:
- POST /api/legal-documents/ingest
- If cloudflared is available, the app updates app_config.legal_ingest_url automatically

4. Start YOLO server

cd D:\Fishy\server\Yolo
uvicorn app:app --host 0.0.0.0 --port 8001 --reload
